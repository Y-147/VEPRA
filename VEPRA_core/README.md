VEPRA

This repository currently provides the core implementation of VEPRA for cross-subject EEG emotion recognition.

Available Code

vepra.py: VEPRA model, DynamicFAP, reliability-guided routing, and prototype transfer.
cssc.py: Cross-Subject Semantic Consistency (CSSC) and high-level semantic alignment.
adv.py: domain-adversarial learning components.
prototype_confidence.py: prototype confidence estimation.

The complete code, including data preprocessing, training, evaluation, configuration files, and reproduction scripts, will be organized and released after the paper is accepted.
